# DSH ChatGPT SIWC

通过官方 Sign in with ChatGPT 开源应用流程，将 ChatGPT 计划接入 DeepSeek Harness。插件免费提供，以 `DSH ChatGPT SIWC` 名称申请授权。

## 安装与更新

### 在 DSH 界面安装

在 DSH 的插件管理页面输入以下 npm 包名：

```text
dsh-plugin-chatgpt-siwc
```

按宿主提示完成安装并启用 **DSH ChatGPT SIWC**；需要重启时按提示重启。当前兼容 DSH `0.2.1-rc.3`，请先核对桌面版本。

需要离线分发或本地验收时，可在插件管理页面安装维护者提供的 `dsh-plugin-chatgpt-siwc-0.9.3.tgz`。开发者可通过下方开发命令构建打包。

### 更新

第三方插件按宿主提示先卸载旧版，再输入相同 npm 包名重新安装；本地包安装则选择新版 `.tgz`。卸载前核对账号与自定义设置，更新后检查登录状态、模型及上下文窗口设置；凭据与设置是否保留取决于宿主的卸载处理，必要时重新登录和配置。

### 开发者 CLI 安装

确认桌面正在使用的 `DSH_HOME` 和 profile 后，通过同版本 CLI 安装本地包，例如在包所在目录执行：

```sh
dsh plugin --profile <桌面实际使用的profile名称> add ./dsh-plugin-chatgpt-siwc-0.9.3.tgz
```

插件的安装位置必须与桌面 profile 一致。CLI 安装前请从桌面设置核对 profile，避免安装到另一套环境。

## 使用

1. 打开设置中的插件页面，选择 **Continue with ChatGPT**，在系统浏览器完成登录及计划使用授权。
2. 登录后刷新模型目录，选择模型并点击“验证连接”。验证会使用少量计划用量。
3. 在 DSH 原有模型选择器选择 `ChatGPT` 提供方下的模型。
4. 直接发送任务，所有会话、子智能体及会话的标题和压缩调用默认可用。
5. 独立调用默认开启，包含 DSH 工具自动审核；升级时已有账号同样开启。之后可在高级设置中关闭，选择会保存。带有会话归属的定时或外部触发任务同样默认可用。
6. 通过“管理用量”打开 ChatGPT 的用量设置；“退出连接”取消当前连接的请求、尝试撤销会话并清除本机令牌。

每个 profile 可以保存多个账号注册，账号列表标记当前使用的账号。点击“添加账号”完成新的浏览器登录，或点击“切换”使用已登录账号。登录成功后激活新账号；取消或失败时继续保留原账号。相同邮箱的不同注册以短标识区分。

切换账号会停止原账号的在途请求并更新模型目录。会话随后使用当前选择的账号。各账号的凭据、本地用量及独立调用设置分别保存；用量区展示当前账号的统计。账号 A 切到 B 再切回 A 时保留 A 的回放范围，网络连接重新建立，回放仍按当前历史核对。退出仅清除所选账号的登录凭据，保留注册映射以便重新登录；退出当前账号时会选择其他已登录账号。退出后重新登录会更新授权代次，旧授权的回放资格随之失效。旧版单账号数据自动迁移。

连接与用量入口集中在插件设置页，模型验证位于“连接诊断”，独立调用开关位于“高级设置”。

目录名称、模型 slug、默认上下文容量、最大容量、可选推理档位及图片能力来自当前账号。缺失字段保持未知，默认上下文与最大容量分别保存。采样使用服务端设置，兼容 DSH 自动审核固定传入的 `temperature: 0`，请求中省略此字段。其他显式 `temperature`、`maxTokens` 和 `stop` 返回配置错误，应清空这些覆盖值。

## 缓存诊断与高级选项

插件设置的“缓存诊断”保留最近 2000 个请求，按普通会话、子智能体、标题生成、压缩、独立调用和连接测试统计。可按类型、模型和连接事件查询全部保留记录，界面展示最近 30 条匹配明细，并可将匹配结果复制为 JSON 或 CSV。DSH 未标注独立调用的具体来源，工具自动审核归入独立调用。

诊断包括缓存读取与写入、计量覆盖率、准备/握手/首事件/首内容等耗时拆分、原生回放统计，以及连接轮换、探活、冷却和前序响应持久化确认。服务端返回的 `prompt_cache_diagnostics` 只提取白名单状态、原因和计数。`completed`、`failed`、`incomplete` 终态提供的有效用量都会记录，同一请求内按账号和响应标识去重。

当前 profile 的 `chatgpt-siwc-diagnostics.json` 保存统计；`chatgpt-siwc-baselines.json` 保存匿名路由与前缀比较基线。内容指纹由 Host 凭据域按 profile 管理的 HMAC 密钥生成，密钥默认有效 24 小时。同一有效密钥下，基线可跨重启比较；密钥轮换后重新建立前缀比较基线。基线仅在最近更新后的 24 小时内参与比较，最多保留 128 条路由、128 条前缀，每条前缀最多 4096 项，文件上限 2 MiB；过期条目在读取或写入时淘汰。

指纹计算有 4 MiB 输入预算、16384 节点及 64 层深度限制。超限时记录跳过原因、清理对应比较基线，用量与传输决策继续正常记录。诊断和基线不保存消息正文或工具内容，具体存储与导出范围见 [PRIVACY.md](<PRIVACY.md>)。

高级设置可选择缓存 TTL（服务端默认、30 分钟、12 小时），并开启服务端缓存对比诊断、配置增量追加或工具增量追加。选项按账号保存；插件按回放范围和模型维护 `unknown` / `supported` / `unsupported` 能力状态，通过实际请求探测。服务端明确拒绝对应可选参数时，后续请求采用兼容路径；其他认证、额度或服务端错误按原类别处理。

续接决策与服务端缓存计量分别展示，缓存归因以返回的证据为准。缓存计量缺失时保持未知；累计请求耗时包含并发重叠。诊断故障在设置页显示，推理继续运行。已有任务不追溯。

## 上下文窗口

在插件设置的“模型”区域选择模型，填写“上下文窗口（token）”并保存，或点击“恢复默认”。页面显示当前生效值、服务端默认值及已知最大值。覆盖设置按账号和模型分别保存，重启后保留；没有旧配置的账号自动使用服务端值。

DSH 的后续模型解析、请求准备及自动压缩容量计算使用该值，已准备的请求继续使用准备时的窗口。数值必须为正整数且不超过服务端已公布的最大窗口；这项设置调整本地预算，实际请求容量由服务端决定。自动压缩还会扣除输出和预留空间。

## 订阅额度

订阅额度展示为可选功能，正常聊天只需 SIWC 登录。“连接 Codex 查看额度”通过官方 Codex app-server 登录并读取订阅额度，只调用账号和额度方法；模型推理使用 SIWC 连接。

额度连接成功后，在设置页点击“关联到当前聊天账号”，确认聊天与额度登录属于同一 ChatGPT 账号和工作区。关联后的额度显示在会话输入区模型选择器旁，悬停或点击可通过进度条与数字查看剩余比例，并查看重置时间、积分和更新时间。浮层与图标跟随宿主主题。邮箱只用于展示，不作为自动关联依据。

Codex 返回稳定账号标识时，关联以匿名指纹保存并跨重启恢复；旧版 Codex 缺少该标识时，关联只在本次运行有效。来源变化或退出额度连接时，关联失效。模型专属额度按服务端 normalModelSlug 匹配，通用额度作为共享窗口显示。

需要本机已有 Codex CLI。默认查找 PATH 和 macOS Codex/ChatGPT 应用内的可执行文件；其他位置可设置 `DSH_CHATGPT_CODEX_BINARY`。独立登录保存于当前 profile 的 `chatgpt-siwc-codex-quota` 目录，由 Codex 管理登录和续期。

设置页和会话标识共享每分钟一次的刷新，页面隐藏时暂停。临时查询失败保留上次结果并显示更新时间和失败状态。尚未关联时，标识提示在设置页确认关联。插件不会自动购买积分、消耗重置权益或切换聊天账号。设置页的状态、模型和额度读取独立进行，后台查询不锁定账号与设置操作。

用量区显示当前账号累计缓存命中率，只统计服务端明确提供缓存计量的请求，按这些请求的缓存 token 除以总输入 token 计算；没有有效样本时显示“—”。

## 会话、缓存与连接复用

每次会话请求携带稳定、匿名化的 `session-id`，按 profile、`replayScope`、DSH 会话、模型和调用用途隔离。`replayScope` 由账号与授权代次（`grantEpoch`）派生；进程重启、令牌续期及账号切回保持范围，退出重登更新范围。发送前会在当前账号与活动选择下重新读取最新凭据，避免使用已轮换的旧令牌。没有会话归属的单次请求使用独立标识和 HTTP。

插件按名称排序工具，稳定序列化 Schema 的对象键。原生回放 v3 以最终 `response.output` 为依据，保留消息分组、ID、phase、annotations、空文本/拒绝内容块、工具调用与加密推理；流式摘要用于实时展示。局部编辑后的回放只采用仍匹配的完整内容块，用户重排以当前顺序为准；压缩或编辑删除的内容不再发送，旧版回放元数据继续兼容读取。

有会话归属的推理优先使用 WebSocket。下一轮先经过 DSH `sessions.flush()` 持久化检查，并核对当前会话中的响应及内容。只有已保存的响应、语义请求设置和完整历史前缀全部匹配，才使用 `previous_response_id` 发送新增输入；服务端缓存对比响应 ID 不参与语义设置比较。其他情况发送完整上下文。

连接池最多保留 32 条空闲连接，运行中请求不计入；优先保护最近 8 个主会话，其余按最近使用顺序回收，同逻辑会话仅保留最新可续接的空闲连接。空闲连接没有固定闲置超时，但有连接总寿命限制：50 分钟后计划轮换、在途请求排空，60 分钟为硬上限，超限连接不再复用。服务端缓存有效期独立于本地连接生命周期。

WebSocket 通过 `ping/pong` 探活；网络变化或需要确认连接健康时先检查连接。握手或无输出断线失败会进入 30 秒至 5 分钟的冷却，冷却期间走 HTTP，到期只允许一个请求探测 WebSocket 恢复。前序响应失效、连接中断、续期及能力回退共用单次请求预算：最多发送 2 次、握手 2 次、续期 1 次、缺失前序响应恢复 1 次。只有状态事件或空占位时仍可在预算内恢复；已输出文本、思考或工具调用后，中断交由 DSH 处理，避免重复输出。

HTTP 在输出前收到明确的 `401/token_expired` 时刷新凭据并在预算内重发一次，保持请求正文与会话标识。临时预刷新失败时可继续使用仍有效的访问凭据；续期开始后，即使发起者取消等待，轮换结果仍会保存。退出、停用和卸载中止请求并清理连接。

WebSocket 使用 Node `ws` 网络连接，HTTP 沿用 Host 的 `fetch`。仅 HTTP 可达的网络会自动回退；实际代理网络与缓存命中用量随桌面验收确认。`session-id` 用作会话关联，缓存复用依赖服务端规则与实际请求前缀。

## 功能与数据边界

- Authorization Code + PKCE、OIDC 签名/issuer/audience/nonce 校验、动态注册、令牌轮换和撤销。
- 官方 `/v1/models` 目录及 `/v1/responses` WebSocket、HTTP/SSE，文本、图片、本地工具调用和加密推理回放。
- DSH 负责历史、压缩、工具审批与执行；插件仅转换当前请求和回放元数据。
- 凭据通过 DSH `ctx.credentials` 的 grant 记录保存，续期使用该服务的跨进程事务。
- host ID 为凭据存储范围内稳定值；连接、授权与本地用量按 profile 目录哈希隔离。
- 用量是本插件本地记录的有效终态计量，输入 token 包含缓存命中；官方计划额度请查看 ChatGPT 设置。
- 网络失败后可刷新模型重试；额度错误会暂停后续推理，管理用量后刷新模型解除本地暂停。
- 停用插件释放监听、网络连接和在途请求，保留账号登录供重新启用；卸载前可先退出连接以清除令牌。

凭据位置及对话传输范围见 [PRIVACY.md](<PRIVACY.md>)。

## 开发

```sh
npm ci
npm run typecheck
npm test
npm run check:release
npm pack
```

`check:release` 会构建插件、检查 npm 包清单，并审计当前仓库文件及打包内容中的隐私信息。维护者的首次发布、trusted publishing 配置和公开快照发布流程见 [RELEASING.md](<RELEASING.md>)。

OAuth 测试使用临时 `127.0.0.1` 监听和人工构造的 JWT；测试不会连接真实账号。客户端按 DSH lazy-CJS factory 格式构建。共享 DSH/Cordis 依赖使用宿主实例，`jose` 与 Host 的 Zod 由插件管理。开发依赖统一使用已修复的 Zod 版本。

流式解析状态机集中维护交错内容块、工具参数和终态顺序；连接池、网络传输、持久化确认与回放投影分别由独立模块负责。Typert 元数据由 Host 插件生命周期统一注册与释放。
