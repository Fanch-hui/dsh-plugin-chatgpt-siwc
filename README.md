# DSH ChatGPT SIWC

通过官方 **Sign in with ChatGPT** 授权，将 ChatGPT 计划接入 DeepSeek Harness。支持文字、图片、工具调用、多账号及订阅额度展示。

**当前版本：0.9.4** · 适配 DSH `0.2.1-rc.3` · MIT

## 工作原理

插件遵循 OpenAI 公开的 [SIWC 开源应用授权流程](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)：用户在官方页面完成 OAuth 授权后，本机插件使用授权凭据调用官方的[模型目录与 Responses API](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)，使用账号获准的 ChatGPT 计划额度。

模型请求由本机直接发送到 OpenAI 官方服务，不经过第三方反向代理或中转服务，也不依赖抓取网页 Cookie、模拟网页请求或绕过额度限制。账号权限、模型访问和用量限制均由 OpenAI 官方服务校验。

## 快速开始

在 DSH 插件管理页面输入 npm 包名，安装并启用：

```text
dsh-plugin-chatgpt-siwc
```

1. 打开插件设置，点击 **Continue with ChatGPT**，在浏览器完成登录和授权。
2. 刷新模型目录，在“连接诊断”中验证连接；验证会使用少量计划用量。
3. 在 DSH 模型选择器中选择 **ChatGPT** 提供方下的模型，开始使用。

登录后，会话、子智能体、标题生成和压缩默认可用。独立调用（含工具自动审核）默认开启，可在高级设置中关闭。

**更新：**按 DSH 提示卸载旧版，再用相同包名安装；离线安装选择新版 `.tgz`。宿主的卸载处理可能清理登录和设置，更新后请检查并按需重新配置。需要重启时按宿主提示操作。

## 多账号

在插件设置中点击“添加账号”完成登录，点击“切换”使用已登录账号。各账号的凭据、模型设置和本地用量分别保存。

所有会话使用当前选中的聊天账号。切换账号会停止原账号正在生成的请求，并更新模型目录；退出连接会清除该账号的本机令牌。

## 订阅额度

额度展示需单独通过 **Codex CLI** 登录；聊天使用前面的 ChatGPT 授权连接。

1. 在“订阅额度”中点击“添加额度账号”，完成 Codex 登录；可添加多个账号。
2. 选择对应的额度账号，点击“关联到当前聊天账号”，确认两者属于同一 ChatGPT 账号和工作区。
3. 为其他聊天账号分别完成关联。

切换聊天账号后，输入区的额度标识自动显示对应账号的额度。悬停查看摘要，点击查看剩余比例、重置时间和积分；设置页的下拉框用于浏览和管理额度账号。

额度每分钟刷新，页面隐藏时暂停。读取失败时保留上次结果与更新时间；退出或移除某个额度账号，仅影响该来源的关联。

插件会查找 PATH 及 macOS Codex/ChatGPT 应用内的 Codex 可执行文件，也可通过 `DSH_CHATGPT_CODEX_BINARY` 指定路径。

## 常用设置

| 设置 | 用途 |
| --- | --- |
| 上下文窗口 | 在“模型”区域按账号、模型保存，影响 DSH 的上下文预算与自动压缩；可恢复服务端默认值。 |
| 独立调用 | 在“高级设置”中控制工具自动审核等独立请求。 |
| 缓存保留时长 | 可选服务端默认、30 分钟或 12 小时。 |
| 缓存高级选项 | 服务端对比诊断、配置增量追加和工具增量追加；按需开启，服务端明确拒绝时自动采用兼容方式。 |
| 缓存诊断 | 查看命中统计、请求耗时及连接事件，支持筛选和复制 JSON／CSV。 |

模型、推理档位和图片能力来自当前账号的模型目录。上下文窗口须为正整数，并受已知最大窗口限制；实际请求容量由服务端决定。

缓存命中率按有效样本的缓存 token ÷ 输入 token 计算，尚无有效样本时显示“—”。诊断保留最近 2000 个请求，不保存消息正文或工具内容。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 找不到模型或能力有变化 | 刷新模型目录，检查当前聊天账号。 |
| 提示采样参数不支持 | 清空自定义的 `temperature`、`maxTokens` 和 `stop`，使用服务端设置。DSH 自动审核的 `temperature: 0` 由插件适配。 |
| 计划用量达到上限 | 通过“管理用量”查看 ChatGPT 设置，恢复后刷新模型解除本地暂停，或手动切换其他已登录账号。 |
| 额度未显示 | 检查本机 Codex CLI、额度登录状态，以及当前聊天账号的关联。 |

## 开发

需要 Node.js 22 或以上，DSH 依赖版本与兼容基线保持一致。

```sh
npm ci
npm run typecheck
npm test
npm run check:release
npm pack
```

`check:release` 包含构建、包清单与隐私审计。OAuth 测试使用本地回环监听和人工构造数据；桌面登录、账号切换与交互由人工验收。
